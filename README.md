# ♟️ Noona (Chess Engine) - 1200 ELO

Trying to build a chess engine built for learning the fundamentals of chess programming.
The project focuses on clarity and correctness rather than playing strength.

Features include - 
- board representation
- legal move generation
- basic evaluation function combined with minimax and alpha-beta pruning.

The engine searches a fixed depth and selects the best move based on material
balance and simple positional heuristics.

This project is intended as a foundation for future improvements such as
quiescence search, move ordering, and transposition tables.

Built for experimentation, learning, and understanding how chess engines work
under the hood.
